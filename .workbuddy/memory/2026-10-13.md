## 第五轮修复（未登录态点 +/- 数量 1-3 秒后变回 1）

**现象**：未登录态，点 +、- 乐观更新生效（数量/金额立即变），但 1-3 秒后又被冲回 1。

**排查**：服务器端 `/cart/change.js` 完全正常（curl 实测 JSON/form 均能正确改数量），带 Origin/Referer 头也 200，`cart` cookie 无 Secure 属性（HTTP localhost 下正常）。问题在前端逻辑——乐观更新后，`changeLine` 无条件 `await fetch('/cart/change.js')` 并用服务器返回覆盖，失败走 catch `loadCart()` 拉旧数据；`loadCart` 未登录时也会无条件 fetch `/cart.js` 覆盖本地。服务器 cookie cart 与本地 localStorage 两套数据不同步 → 旧数据覆盖 → "变回 1"。

**修复**（`assets/theme.js`）：
- `loadCart`：未登录且本地已有缓存时，fetch `/cart.js` 结果 `return` 不覆盖（信任本地乐观值）
- `changeLine` 同步分支：登录态 await + 覆盖 + 失败 `loadCart`；未登录态改为 `fire-and-forget` 尽力同步（`.catch` 忽略），不覆盖本地、失败不回滚
- 加购逻辑：`/cart/add.js` 成功后先 `currentCart = cart; cacheWrite(cart)` 再 `openDrawer()`，保证新商品立刻显示（否则被 loadCart 的 return 挡住）

**结论**：未登录 = 本地 localStorage 为唯一数据源，服务器 fire-and-forget 尽力同步；登录 = 服务器为准。彻底消除"变回 1"。
